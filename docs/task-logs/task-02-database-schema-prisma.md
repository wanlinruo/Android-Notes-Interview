# Task 2: Database Schema & Prisma Setup

**Status:** Completed
**Date:** 2026-04-01

## Summary

Initialized Prisma ORM and defined the complete database schema with all 8 models and 5 enums for the Android Knowledge Hub.

## Completed Steps

1. **Initialized Prisma** — `npx prisma init` created `prisma/schema.prisma` and `prisma.config.ts` (Prisma 7 format)
2. **Installed dotenv** — Required by `prisma.config.ts` for loading DATABASE_URL
3. **Wrote database schema** — 8 models (User, Category, Tag, Article, ArticleTag, Favorite, Progress, Comment) and 5 enums (Role, ArticleType, ArticleStatus, TagType, ProgressStatus)
4. **Created Prisma client singleton** — `src/lib/prisma.ts` with global singleton pattern for dev hot-reload
5. **Generated Prisma client** — `npx prisma generate` output to `src/generated/prisma/`
6. **Validated schema** — `npx prisma validate` confirmed schema is valid

## Prisma 7 Adaptations

The plan was written for Prisma 5/6. Prisma 7 introduced changes:
- **Client provider**: `prisma-client` instead of `prisma-client-js`
- **Config file**: `prisma.config.ts` handles datasource URL (instead of inline in schema)
- **Output directory**: Client generated to `src/generated/prisma/` (instead of `node_modules/.prisma/client`)
- **Import path**: `import { PrismaClient } from "@/generated/prisma"` (instead of `@prisma/client`)

## Docker & Database Setup

- Installed Docker Desktop (via DMG download, Homebrew cask had a bug)
